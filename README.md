# Smart Campus IoT 🌱

Sistema de monitoreo ambiental para aulas mediante tecnologías IoT.

Proyecto escolar de 6.º año de Informática A (Grupo G4), desarrollado con ESP32-C3, sensores ambientales, Wi-Fi, MQTT y un dashboard web.

## Documentación

**[Abrir la documentación del proyecto](index.html)**

Desde la web también se puede acceder al dashboard de monitoreo.

## Tecnologías
- ESP32-C3 y sensores ambientales.
- Arduino / C++.
- Wi-Fi y MQTT.
- HTML, CSS y JavaScript.
